# 飞书 IM 网关

设置字段与首次对话流程见 [设置页帮助](settings/zh-CN/im-gateway.md)（[English](settings/en-US/im-gateway.md)），也可在 **设置 > IM 网关** 点击标题旁的问号，在应用内阅读。本文集中维护完整业务规则与排障说明。

IM 网关把飞书消息接到 aiopsterm 终端，支持选择已有终端和新建本机、SSH 终端。当前支持飞书企业自建应用，通过长连接接收消息，不需要公网回调地址。入口是 **设置 > IM 网关**，默认关闭。桌面应用和目标终端必须保持运行；关闭窗口后终端不可用时，网关不能独立执行命令。

绑定后普通聊天直接写入所选终端并回车，终端输出自动发回该聊天。网关本身不调用大模型；如果终端正在运行 Codex 等交互程序，消息就输入该程序。未来渠道可通过适配器接入，当前只能配置一个飞书应用。技术边界见 [IM 网关架构](../technical/im-gateway.md)。

## 配置飞书

下面按首次配置顺序操作。使用的是**企业自建应用机器人**；群里的自定义 Webhook 机器人不能替代此接入方式。准备好可管理该应用的飞书账号，并保持 aiopsterm 运行。

1. 打开[飞书开发者后台](https://open.feishu.cn/app)，创建企业自建应用，填写名称和描述。在 **添加应用能力** 中添加 **机器人**。
2. 在 **凭证与基础信息** 找到 App ID 和 App Secret，稍后填入 aiopsterm。不要把 Secret 发到聊天或写进项目文档。
3. 打开 **权限管理 > 开通权限**，选择 **应用身份权限**，按下表搜索权限标识并开通。单聊控制和截图需要前三项；仅使用单聊时无需群聊权限。

   | 用途 | 权限 |
   | --- | --- |
   | 接收用户发给机器人的单聊消息 | `im:message.p2p_msg:readonly` |
   | 以机器人身份回复文字、卡片和图片 | `im:message:send_as_bot` |
   | 上传终端截图 | `im:resource`，后台名称为“获取与上传图片或文件资源”；若提供独立的 `im:resource:upload`，可只开通上传权限 |
   | 可选群聊 | 接收群聊中 @ 机器人的消息权限 |

4. 获取自己的 `open_id`：在飞书 API 调试台切换到**当前应用**，打开“发送消息”接口，将 `receive_id_type` 选为 `open_id`，点击“快速复制 open_id”，选择成员并复制。只需复制 ID，不需要点击“开始调试”或实际发送消息。也可从当前应用的用户信息 API 或事件调试数据中取得；姓名、邮箱和另一应用下的 open_id 都不能替代。
5. 打开 aiopsterm **设置 > IM 网关**，填写 App ID、App Secret、授权用户 open_id。首次使用可只填自己的 open_id，授权群聊 chat_id 留空，先验证单聊。
6. 选择终端授权范围：勾选 **all 模式**，允许本机和全部已保存的 SSH 主机（包含以后新增的主机）；或填写具体资产 ID，并单独选择是否允许本机终端。SSH 主机必须已保存在 aiopsterm 中。all 只扩大终端范围，仍检查用户和群聊白名单，不表示任何人都可控制终端。配置文件表示为 `allowedAssetIds: ["all"]`，`*` 不作为通配符。
7. 勾选启用，点击 **保存并应用**，等待连接状态变为 **已连接**。“设置已保存”不等于“已连接”。先建立连接，再进行下一步，可避免飞书保存长连接配置时提示客户端尚未连接。
8. 在飞书后台 **事件与回调** 中完成两项订阅，接收方式都选长连接：**事件配置**添加 `im.message.receive_v1`；**回调配置**添加 `card.action.trigger`。前者接收聊天消息，后者处理终端选择卡片按钮。两项都要保存，不需要公网回调地址。
9. 打开 **版本管理与发布**，创建版本并按后台要求发布；应用可用范围必须包含将要使用机器人的成员，先供自己使用时只选自己。若企业要求管理员审核，需等审核通过。后续修改按后台提示处理：免审且已开通的权限可能立即生效，不能一概认为每次加权限都必须另发版本。
10. 在飞书客户端找到该应用机器人并进入单聊，按下表验证。找不到机器人时，检查发布状态、机器人能力和成员可用范围。

| 首次验证 | 预期结果 |
| --- | --- |
| 发送 `/help` | 收到命令说明，证明消息接收和回复可用 |
| 发送 `/sessions`，点击一个终端 | 收到绑定结果；若没有终端，用 `/new` 新建本机或已授权的 SSH 终端 |
| 发送 `/binding` | 显示所选终端及连接状态 |
| 在普通 shell 中发送 `pwd` | 命令进入绑定终端，目录输出回传；终端已运行 Codex 时，文字会输入 Codex |
| 发送 `/screenshot` | 收到绑定终端当前屏幕图片；文字正常但图片上传失败时，先核对图片权限 |

需要群聊时，再开通对应群消息权限、将机器人添加到群、填写该群的 `chat_id`，并由已授权用户 @ 当前机器人发送命令。群聊授权不能替代用户授权。故障定位见下文“凭据与排障”。

官方参考：[事件处理与长连接](https://open.feishu.cn/document/server-side-sdk/nodejs-sdk/handling-events)、[接收消息事件](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/im-v1/message/events/receive)、[长连接接收卡片回调](https://open.feishu.cn/document/event-subscription-guide/callback-subscription/receive-and-handle-callbacks)、[官方 Node SDK](https://github.com/larksuite/node-sdk)。

## 配置生效与升级

点击“保存并应用”会重新建立网关连接并立即应用配置，不需要重启整个软件。新增或修改飞书事件、卡片回调、权限后，按后台提示发布应用配置；标为免审且已开通的权限可能立即生效，应以实际接口结果确认。升级 aiopsterm 的功能代码需要启动包含这些功能的新版本；仅重启旧安装包不会获得新功能。

重启后发送新的 `/sessions` 卡片并重新选择终端。旧卡片会失效，原绑定的 sessionId 也可能因终端恢复而变化。真实消息与卡片操作是否成功，需要在已发布的飞书应用中验证，不能仅凭设置页显示“已连接”判断。

## 命令

| 消息 | 行为 |
| --- | --- |
| `/help`、`/help key`、`/keymap` | 查看全部命令或完整按键映射 |
| `/screenshot` | 发送当前绑定终端的屏幕图片 |
| `/sessions` | 返回已连接、已授权终端的选择卡片，每页 8 项，可翻页和新建终端 |
| `/new` | 返回新建终端卡片：本机及授权的已保存 SSH 主机 |
| 普通文字 | 绑定后输入当前终端并回车；未绑定时提示选择终端 |
| `/bind <sessionId>` | 保留手工绑定入口，日常使用卡片即可 |
| `/binding` 或 `/status` | 查看当前绑定的终端名称、主机和连接状态；未绑定或已断开时明确提示 |
| `/unbind` | 解除当前绑定 |
| `/run <单行命令>` | 向绑定终端输入文字并发送回车 |
| `/send <单行文字>` | 仅输入文字，不发送回车 |
| `/read` | 读取当前终端屏幕末尾 40 行，超过长度限制时保留末尾内容 |
| `/key ctrl shift c`、`/key ctrl alt c`、`/key ctrl shift up` | 发送 Ctrl+Shift+C、Ctrl+Alt+C、Ctrl+Shift+上方向键等组合，不额外回车 |
| `/key ctrl c`、`/key esc` | 向绑定终端发送 Ctrl+C、Escape，不额外回车 |
| `/key enter`、`/key tab`、`/key up` | 发送回车、Tab、上方向键；也支持 down/left/right、home/end、pageup/pagedown、backspace/delete、F1-F12 等 |
| `/interrupt` | 向绑定终端发送 Ctrl+C |

普通消息输入当前程序，不会自动启动 Codex。单行消息直接写入并回车，多行或含制表符的消息使用终端 bracketed paste 后回车，最多 4096 字符；终端中的程序决定如何处理粘贴内容。`/run` 和 `/send` 保留最多 2048 字符的单行输入。禁止消息自带终端控制字符；用 `/key <按键>` 发送控制键，每条消息一个按键。修饰键支持 Ctrl、Alt、Shift 组合，可用空格、加号或连字符分隔，例如 `ctrl shift c`、`ctrl+shift+c`；顺序和大小写不限，重复修饰键、未知键名及多个连续按键会被拒绝。组合键发送给终端内程序，不执行桌面复制、粘贴或系统快捷键。Ctrl+Shift 字符等扩展按键需要目标程序支持相应键盘协议；不支持的程序可能忽略或显示转义序列，网关不会把它偷偷降级成 Ctrl+C。网关斜杠命令保留用于管理：要在 Codex 中输入 `/model`，发送 `/run /model`；在终端中输入路径命令也可用 `/run`。密码等敏感数据不要通过聊天输入。

绑定后先发送最近屏幕，随后持续回传输出，无需反复 `/read`。普通追加输出按约 1 秒合并，每批最多 6000 字符；颜色、控制序列和提及标记被清理。Codex、编辑器等使用光标重绘的 TUI 把最近 40 行屏幕放在同一张输出卡片中更新，最多约 3 秒一次；动画、计时和状态栏变化不会不断新增消息。相同屏幕和行尾空格变化不重复发送。普通文字、`/run` 或 `/key enter` 提交新输入后，后续变化的屏幕使用新卡片；`/key esc`、`/key ctrl c` 等按键继续更新当前卡片。卡片仅保留最近屏幕，不是完整输出历史。持续高速输出超过每个绑定 64000 字符的待发送上限时，省略较早内容并明确提示；完整内容仍需在桌面查看。发送失败后暂停该绑定的输出订阅，在恢复网络后用 `/status` 或重新选卡片恢复；输入不会自动重发。

新建终端复用桌面终端和已保存主机的连接流程。SSH 需要密码、MFA 或连接失败时，在桌面处理；创建的 tab 保留，未连接成功不会替换原绑定。卡片只对请求该卡片的用户和聊天有效，10 分钟后或应用重启后失效；点击时再次检查权限和连接。重复投递同一选择不会重复创建终端。

直接绑定另一个终端（点击卡片、执行 `/bind` 或成功新建）会自动替换旧绑定，并停止旧终端的输出回传，不必先 `/unbind`。切换失败时保留原绑定；旧终端和其中的进程继续运行。已发送到飞书的内容不会撤回。

输入回执不代表命令成功或执行完成。`/interrupt` 发送 Ctrl+C，`/unbind` 只停止该聊天的输入绑定和输出回传，不关闭终端或终止其中进程。

群聊必须同时满足：群 `chat_id` 已授权、发送者 `open_id` 已授权、消息明确 @ 当前机器人。命令放在 @ 机器人之后。群内回复和终端输出对所有群成员可见。不同用户、聊天、租户及应用各有自己的绑定；绑定不会继承桌面当前焦点。

绑定终端断开、关闭或被新会话替换后，输出订阅会停止并通知一次。此时再发普通消息、按键或 `/binding` 等命令，会明确回复绑定已失效，本条输入未写入终端；如果写入期间出错，则回复操作失败，不声明输入一定没有执行。连接恢复不会自动重发输入，也不会切换到当前活动终端。撤销权限、解绑、停用网关不发送断开通知。

终端断线重连或应用重启后，原 sessionId 可能失效，需要重新发送 `/sessions` 并点击选择。重新启用网关后，已有有效绑定在收到 `/status` 或下一条输入时恢复输出订阅。网关不会偷偷切到重建的终端。修改权限、停用网关会停止接收并丢弃尚未执行的排队操作，已经发给终端的命令不会回滚或被自动中断。

## 凭据与排障

App Secret 使用操作系统凭据加密保存，不返回设置页、不进入普通用户配置导出。已保存后留空即可保留。更换 App ID 需要重新填写 Secret。删除 Secret 时先取消启用，再勾选清除并保存。Linux 必须有可用的系统密钥环，不能使用明文回退后端。

- 连接失败：检查 App ID/Secret、机器人能力、网络以及应用权限和发布状态；重新保存会重建连接。
- 已连接但不响应：检查用户 open_id 是否属于当前应用、消息事件是否订阅、用户是否在应用可用范围内。群聊还要检查 chat_id、@ 对象及群消息权限。未授权消息不会得到回复。
- 卡片按钮无响应：检查飞书“回调配置”已选择长连接并订阅 `card.action.trigger`，配置修改已发布；旧卡片请重新 `/sessions`。
- 没有终端：点击新建终端，或在桌面打开主机并连接；核对资产 ID 授权或启用 all 模式。
- Codex 动画导致不断新增近似消息：升级到包含输出卡片更新的新版本；旧进程不会自动加载修复。更新卡片失败会暂停输出，不会改为不断新发消息。
- 命令已发送但看不到结果：使用 `/read` 检查屏幕，`/status` 恢复输出订阅。不要因为消息回复失败就重复发送有副作用的命令；先检查桌面终端。
- 查看 **设置 > 关于 > 打开日志目录** 中的 `aiopsterm-runtime.log`，筛选 `im.gateway`。日志仅记录消息标识、用户/聊天标识、操作类型和结果，不记录命令、终端输出或凭据。

应用 userData 目录下，`im-gateway.json` 保存网关配置与加密 Secret，`im-gateway-state.json` 保存消息去重凭据和绑定。它们不包含命令历史。状态文件损坏时网关拒绝启动；排障时先退出应用、备份文件，不要在运行中清除去重记录。

## 按键映射

`/help` 包含映射说明，`/keymap` 或 `/help key` 单独查看完整按键帮助，无需先绑定；`/keymap ctrl c` 等带参数的形式仍返回完整映射，不发送按键。发送按键前需绑定已授权、已连接的终端。

| 按键 | 可用名称或示例 |
| --- | --- |
| Escape | `esc`、`escape` |
| 回车 | `enter`、`return`、`cr` |
| 制表、空格 | `tab`、`space` |
| 退格、删除、插入 | `backspace` / `bs`、`delete` / `del`、`insert` / `ins` |
| 方向键 | `up`、`down`、`left`、`right`，也支持 `arrowup` 等名称 |
| 行首、行尾 | `home`、`end` |
| 翻页 | `pageup` / `pgup`、`pagedown` / `pgdn` |
| 功能键 | `f1` 至 `f12` |
| 单个字符 | `/key y`，只输入 y，不追加回车 |
| 控制组合 | `/key ctrl c` 中断；`/key ctrl d`；`/key shift tab` |
| 三键组合 | `/key ctrl shift c`、`/key ctrl alt c`、`/key ctrl shift up` |

修饰键为 `ctrl`（别名 `control`、`c`）、`alt`、`shift`，可以组合；空格、加号、连字符分隔，顺序和大小写不限。每条消息只发送一个按键；重复修饰键、未知名称、多个连续按键会被拒绝。扩展组合需要终端程序支持，不能当作桌面复制粘贴；不会将 Ctrl+Shift+C 降级为 Ctrl+C。

## 查看终端截图

发送 `/screenshot` 获取绑定终端当前屏幕的 PNG 图片，可查看 Codex 更新选择、确认菜单和选中行。截图从终端核心的字符、颜色和高亮生成，保留当前行列布局；字体渲染可能与桌面略有差异，不包含鼠标、闪烁光标、窗口边框或其他应用。读取的是终端当前输出底部的屏幕，不是手动滚动到的历史位置；后台标签无需切换到前台。尺寸最多 4096 像素，过大的屏幕等比缩小；不保存本地截图文件。

这不调用系统桌面录屏接口，不需要系统录屏权限。仍必须通过用户、群聊和终端授权，图片会上传到飞书并发送到当前对话。飞书应用需开通应用身份权限 `im:resource`（获取与上传图片或文件资源）。若后台提供较小范围的 `im:resource:upload`，也可只开通该上传权限；后台未提供时使用 `im:resource`。权限标为免审且已开通时可直接验证上传；有待发布提示时再按后台流程发布，无需重启 aiopsterm。返回 `99991672` 表示当前应用缺少接口要求的权限，应核对应用、权限类型及发布状态；上传失败会回复文字提示，可用 `/read` 查看文字。生成或上传期间解绑、终端替换、授权撤销时不继续发送图片。

如果机器人不认识 `/key`、`/help key` 或 `/screenshot`，请退出旧 aiopsterm 并启动包含这些功能的新构建。只在飞书后台发布机器人不会更新本机软件代码；重启后用 `/sessions` 重新选择终端。退出前先处理正在运行的终端任务。
