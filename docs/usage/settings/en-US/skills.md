# Skills Settings

This page lives under `Settings -> Host Agent -> Skills`. It manages local skill packages. Enabled skills can be attached to AI chat context.

## Top Actions

- Open Folder: Opens the user Skills directory.
- Reload: Reloads Skills from the local directory.
- Import: Imports a Skill zip package.
- Create: Creates a new Skill.

## Skill List

- Enable switch: Enables or disables the Skill.
- Edit: Edits an editable Skill.
- Export: Exports the Skill as a zip package.
- Delete: Deletes the Skill.

## Skill Modal

- Skill Name: Skill name. Existing Skill names cannot be changed from edit mode.
- Description: Describes what the Skill does.
- Content: Main Skill content, usually task instructions, workflow constraints, or domain knowledge.
- Create / Save: Writes the Skill locally.

Keep Skills focused. Avoid mixing unrelated rules into one Skill.
