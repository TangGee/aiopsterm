# About

This page provides version, update, and diagnostics entry points.

## App Information

- Version text: Shows the current version or available new version.
- Check Update: Checks for updates.
- Check Update (Latest Version): Indicates the current version is latest.
- Download Update: Downloads an available update package.
- Downloading: Shows download progress.
- Install: Requests OS installer handoff after download.
- Install Requested: The install request has been submitted.
- Check Update Error: Update check failed and can be retried later.

## Diagnostics

- Open Log Dir: Opens the local log directory.
- Open Feedback Report: Generates and opens a local feedback Markdown report with version, platform, log directory, and documentation path metadata.

About does not directly modify business configuration. It is mainly for upgrades, logs, and feedback.
