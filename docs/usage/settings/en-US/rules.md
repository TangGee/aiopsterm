# Rules Settings

This page manages User Rules. Rules constrain Agent behavior during conversation and command generation.

## Options

- Add Rule: Creates a new rule and starts editing.
- Rule content: The rule text. Prefer clear, actionable constraints.
- Done: Saves the rule.
- Cancel: Discards the current edit.
- Enable switch: Enables or disables the rule for later AI/Agent context.
- Edit: Edits the rule text.
- Delete: Removes the rule.

Rules are best for long-lived preferences and safety boundaries. Temporary task requirements are better written in the current conversation.
