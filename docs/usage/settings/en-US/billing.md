# Billing Overview

This page shows the current account subscription and budget state.

## Signed Out

- Login: Opens the login entry. Subscription, budget, and usage ratio require sign-in.

## Signed In

- Account Center: Opens the current account center.
- Email: Current account email.
- Subscription: Current subscription type.
- Subscription Expires At: Subscription expiration time. `Never` means no expiration time.
- Budget Reset At: Budget reset time.
- Ratio: Budget or usage ratio. Higher percentages indicate higher usage.

Billing shows account and budget snapshots. It does not directly change model or request behavior.
