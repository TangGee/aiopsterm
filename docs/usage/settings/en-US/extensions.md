# Extension Settings

This page controls local terminal enhancements.

## Options

- Autocomplete: Enables or disables terminal command suggestions.
- Alias: Enables or disables alias assistance.
- Keyword Highlighting: Enables terminal keyword highlighting. Highlighting changes rendering only; it does not mutate raw terminal output.
- Keyword Highlighting Configuration: Opens the JSON editor for keyword-highlight rules. Rules can define name, scope, match type, pattern, and style.

Saved keyword-highlight configuration is written to a local config file and used for later terminal input/output rendering.
