# 关于

本页提供版本、更新和诊断入口。

## 应用信息

- 版本说明：展示当前版本，或在检查到更新后展示新版本信息。
- Check Update：检查是否有可用更新。
- Check Update (Latest Version)：表示当前已是最新版本。
- Download Update：检查到更新后下载更新包。
- Downloading：更新包下载中，会显示进度。
- Install：下载完成后请求系统安装器接管安装。
- Install Requested：系统安装请求已提交。
- Check Update Error：更新检查失败，可在网络或本地更新服务恢复后重试。

## 诊断

- Open Log Dir：打开本地日志目录，用于排查问题。
- Open Feedback Report：生成并打开本地反馈报告 Markdown，包含版本、平台、日志目录和文档路径等诊断信息。

关于页不会直接修改业务配置，主要用于升级、日志和反馈。
