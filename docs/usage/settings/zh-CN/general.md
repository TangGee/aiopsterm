# 通用设置

本页控制应用级外观、语言、默认布局和内置编辑器行为。

## 基础设置

- 主题：切换应用整体配色。`系统` 跟随操作系统深浅色；`默认` 是 aiopsterm 内置基础主题；`官方` 是预置的第三方风格主题。
- 背景：控制应用外层背景。`默认背景` 关闭自定义背景；预设背景会应用内置低干扰背景；上传按钮可选择本地 JPG、PNG、WebP 或 GIF 作为自定义背景。
- 自定义背景删除：删除当前保存的自定义背景，并恢复为无背景状态。
- 透明度：只在已选择背景时出现，控制背景图片透出强度。数值越低，背景越不明显。
- 亮度：只在已选择背景时出现，控制背景图片亮度。用于避免背景影响文字可读性。
- 默认布局：选择应用启动或恢复时优先进入 `Terminal` 还是 `Agents`。
- 语言：切换界面语言。选择 `跟随系统` 时会根据系统语言自动解析到支持的语言。
- 水印：控制应用背景角落的 `aiopsterm` 水印是否显示。
- 入门引导：打开交互式引导，按模块提示你完成界面、资产、设置和 AI 工作流的基础配置。

## 编辑器设置

这些选项只影响文件编辑器、知识库编辑器、SQL 编辑器和 JSON 配置编辑器，不影响终端字体，也不影响 AI 输入框。

- 字体大小：设置编辑器文本字号。
- 行高：设置编辑器每行高度。设为 `0` 时使用系统根据字号推导的默认行高。
- 字体：设置编辑器字体族。只有系统安装或浏览器能匹配到对应字体时才会有明显效果。
- Tab Size：设置 Tab 等价的空格数量。
- 自动换行：开启后长行在编辑器可视区域内换行；关闭后长行横向滚动。
- Minimap：控制编辑器右侧代码缩略图是否显示。
- Mouse Wheel Zoom：开启后可用鼠标滚轮缩放编辑器字号。
