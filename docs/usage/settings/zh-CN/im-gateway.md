# IM 网关设置

在飞书、Telegram 或百度如流中选择 aiopsterm 终端、打开新的本机或 SSH 终端，并通过聊天输入和接收输出。入口为 **设置 > IM 网关**；标题旁的问号打开本文。桌面应用需要保持运行。

## 平台选择

一次启用一个平台。选择 Telegram 或百度如流后，界面显示该平台的身份字段和接入提示；完整步骤及限制见 [Telegram 与百度如流配置](../../im-platforms.md)。Telegram 使用 Bot ID / Bot Token；如流使用 Agent ID / App Key / App Secret。切换后重新填写授权用户/群，保存会停止旧平台。

Telegram 在群内使用 `/sessions@机器人用户名` 或 `@机器人用户名 pwd`；暂不支持话题。终端选择用按钮，截图以 PNG 文件发送。如流在群内必须通过客户端 @ 当前机器人；列表返回 `/select <令牌>`，复制发送即可选择，普通输出自动回传，连续重绘静止 4 秒后发屏幕，图片小于 1 MiB。平台另有按钮回调刷新卡片能力，当前应用尚未接入；详见[接口边界](../../../technical/im-gateway.md#如流-openhub-接口边界)。下面的飞书权限步骤只适用于飞书。

## 配置与授权

飞书应用创建、权限、用户 open_id 获取、长连接事件和卡片回调发布步骤集中在 [飞书 IM 网关](../../im-gateway.md)。截图还需开通应用身份权限 `im:resource`（获取与上传图片或文件资源）；若后台提供 `im:resource:upload`，可只开通上传权限。按后台提示确认生效或发布，详见上述配置说明。需要同时配置 `im.message.receive_v1` 和 `card.action.trigger`，否则可能收到卡片却无法点击操作。

| 设置 | 用途 |
| --- | --- |
| App ID / App Secret | 飞书企业自建应用凭据；已有 Secret 留空表示保留 |
| 授权用户 open_id | 当前应用下可操作终端的用户；至少填写一个 |
| 授权群聊 chat_id | 留空仅允许单聊；群聊还需授权用户 @ 当前机器人 |
| all 模式 | 允许本机和全部已保存的 SSH 主机，也包含之后新增的主机；仍检查用户和群聊白名单 |
| 指定资产 ID / 允许本机终端 | 未勾选 all 时，分别授权指定主机和本机；无需先连接主机即可授权 |

点击 **保存并应用** 后配置立即生效，查看连接状态是否为 **已连接**。更新飞书权限或回调后，按后台提示保存或发布；免审且已开通的权限可能立即生效，需用实际操作确认。升级 aiopsterm 功能则需要启动新版本；重启后重新发送 `/sessions` 并选择终端，旧卡片不能继续使用。

## 通过卡片开始对话

1. 单聊机器人发送 `/sessions`，按终端名称选择，不必复制 sessionId。列表支持翻页。
2. 没有需要的终端时，点击 **新建终端**，或发送 `/new`，选择本机或已授权的 SSH 主机。应用创建新的 tab，连接成功后自动绑定。
3. 直接发送 `pwd` 等文字，消息会输入绑定终端并回车，输出自动回传。如果终端已运行 Codex，文字就发给 Codex。
4. 换终端时再次 `/sessions` 选择，或使用 `/bind <sessionId>`；成功后自动停止旧绑定的输出，不必先 `/unbind`。切换失败保留旧绑定，旧终端仍继续运行。

`/binding`（或 `/status`）查看当前绑定的终端和连接状态。`/key ctrl shift c`、`/key ctrl alt c`、`/key ctrl shift up` 支持三键组合，也可写为 `ctrl+shift+c`。按键交给终端内程序处理，不触发桌面复制等快捷键；扩展组合键是否有效取决于目标程序支持。

`/key ctrl c` 或 `/interrupt` 发送 Ctrl+C；`/key esc` 发送 Escape；`/key enter`、`/key tab`、`/key up` 等发送对应按键，均不额外回车；`/send <文字>` 只输入不回车；`/unbind` 停止当前聊天与终端的绑定，不关闭终端。向 Codex 等程序输入 `/model` 时使用 `/run /model`，避免与网关命令混淆。

终端断开或关闭会通知一次；继续发消息会明确提示绑定失效，需重新选择终端，不会自动重发此前输入。

SSH 密码、MFA 或连接失败需要在桌面处理，创建的 tab 会保留。普通输出分批发送；Codex 等 TUI 在同一张输出卡片中更新最近屏幕，最多约 3 秒一次，动画不会不断新增消息。提交下一条普通消息后使用新输出卡片。详细限制及排障见 [使用与命令说明](../../im-gateway.md)。

## 按键帮助与截图

`/help` 查看命令及按键映射，`/keymap` 或 `/help key` 单独查看完整按键表，无需绑定；`/keymap ctrl c` 也只返回映射，不发送按键。支持 Escape、回车、Tab、空格、方向键、Home/End、PageUp/PageDown、退格/删除/插入、F1-F12、单个字符及 Ctrl/Alt/Shift 组合。完整名称、别名及协议限制见 [按键映射](../../im-gateway.md#按键映射)。

`/screenshot` 将绑定终端的字符、颜色和选中行生成图片发回当前对话，后台标签也可使用；只包含终端当前屏幕，不采集系统桌面，因此不需要系统录屏权限。仍检查绑定和授权，飞书图片上传失败时会回复错误并提示 `/read`。图片不含鼠标、闪烁光标和应用边框，字体可能略有差异。详见 [截图说明](../../im-gateway.md#查看终端截图)。旧软件不识别这些命令时，需要启动新构建；仅重新发布飞书应用不能更新本机功能。
