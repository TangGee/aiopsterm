# IM 网关设置

在飞书中选择 aiopsterm 终端、打开新的本机或 SSH 终端，并通过聊天输入和接收输出。入口为 **设置 > IM 网关**；标题旁的问号打开本文。桌面应用需要保持运行。

## 配置与授权

飞书应用创建、权限、用户 open_id 获取、长连接事件和卡片回调发布步骤集中在 [飞书 IM 网关](../../im-gateway.md)。需要同时配置 `im.message.receive_v1` 和 `card.action.trigger`，否则可能收到卡片却无法点击操作。

| 设置 | 用途 |
| --- | --- |
| App ID / App Secret | 飞书企业自建应用凭据；已有 Secret 留空表示保留 |
| 授权用户 open_id | 当前应用下可操作终端的用户；至少填写一个 |
| 授权群聊 chat_id | 留空仅允许单聊；群聊还需授权用户 @ 当前机器人 |
| all 模式 | 允许本机和全部已保存的 SSH 主机，也包含之后新增的主机；仍检查用户和群聊白名单 |
| 指定资产 ID / 允许本机终端 | 未勾选 all 时，分别授权指定主机和本机；无需先连接主机即可授权 |

点击 **保存并应用** 后配置立即生效，查看连接状态是否为 **已连接**。更新飞书权限或回调后，还需要在飞书后台发布配置。升级 aiopsterm 功能则需要启动新版本；重启后重新发送 `/sessions` 并选择终端，旧卡片不能继续使用。

## 通过卡片开始对话

1. 单聊机器人发送 `/sessions`，按终端名称选择，不必复制 sessionId。列表支持翻页。
2. 没有需要的终端时，点击 **新建终端**，或发送 `/new`，选择本机或已授权的 SSH 主机。应用创建新的 tab，连接成功后自动绑定。
3. 直接发送 `pwd` 等文字，消息会输入绑定终端并回车，输出自动回传。如果终端已运行 Codex，文字就发给 Codex。
4. 换终端时再次 `/sessions` 选择，或使用 `/bind <sessionId>`；成功后自动停止旧绑定的输出，不必先 `/unbind`。切换失败保留旧绑定，旧终端仍继续运行。

`/key ctrl c` 或 `/interrupt` 发送 Ctrl+C；`/key esc` 发送 Escape；`/key enter`、`/key tab`、`/key up` 等发送对应按键，均不额外回车；`/send <文字>` 只输入不回车；`/unbind` 停止当前聊天与终端的绑定，不关闭终端。向 Codex 等程序输入 `/model` 时使用 `/run /model`，避免与网关命令混淆。

SSH 密码、MFA 或连接失败需要在桌面处理，创建的 tab 会保留。普通输出分批发送；Codex 等 TUI 在同一张输出卡片中更新最近屏幕，最多约 3 秒一次，动画不会不断新增消息。提交下一条普通消息后使用新输出卡片。详细限制及排障见 [使用与命令说明](../../im-gateway.md)。
