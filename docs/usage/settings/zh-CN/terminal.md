# 终端设置

本页控制新建终端会话和已打开终端面板的默认表现。

## 终端基础选项

- 终端类型：设置 xterm 的 `termName`，并作为新建本地终端、SSH shell、relay shell 的 `TERM` 类型传给后端。它主要影响程序能力探测、颜色能力和全屏程序兼容性，通常不会直接改变外观。
- 字体：设置终端字体族。默认使用各平台系统等宽字体，并依次兼容 macOS 的 SF Mono/Menlo、Windows 的 Cascadia Mono/Consolas 和 Linux 的 DejaVu/Noto/Liberation Mono。
- Ubuntu Terminal 主题：在通用设置的主题里选择 `Ubuntu Terminal` 后，会使用接近 Ubuntu/GNOME Terminal 的紫色实底背景和 ANSI 色板。如果系统安装了 `Ubuntu Mono`，这里再选择 `Ubuntu Mono` 会更接近原生终端字形。
- 字体大小：设置终端默认字号，新安装默认值为 `13`。已打开面板如果有单独缩放，面板内缩放会优先。
- ScrollBack：设置终端可回滚历史行数。数值越大，保留历史越多，也会占用更多内存。
- 光标样式：选择块状、竖线或下划线光标。
- 光标闪烁：控制终端光标是否闪烁。
- 行高：设置终端行距比例，新安装默认值为 `1.3`。过低可能显得拥挤，过高会减少单屏可见行数。

## 交互和 SSH

- Pinch Zoom：控制触控板缩放或 Ctrl/Meta + 鼠标滚轮是否调整终端字号。
- 显示关闭按钮：控制终端标签页关闭按钮是否显示。
- SSH Agents：控制是否启用 SSH Agent 相关入口。该功能用于把选定密钥加入 agent，使后续 SSH 认证可以通过 agent 提供密钥。
- SSH Agent 设置：在启用 SSH Agents 后出现。可从密钥链选择密钥加入 agent，也可移除已加入的密钥。
- 鼠标事件 - 中键：设置终端中键动作，可选择无动作、粘贴剪贴板、显示右键菜单或关闭当前标签。
- 鼠标事件 - 右键：设置终端右键动作，可选择无动作、粘贴剪贴板或显示右键菜单。

如果终端里看到能力查询相关字符，通常和 `TERM` 能力探测或历史回放有关；新终端会按当前终端类型和兼容逻辑创建。
