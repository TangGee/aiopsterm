# 扩展设置

本页控制终端上的本地增强能力。

## 选项

- 自动补全：控制终端命令建议是否启用。关闭后不会展示命令补全建议。
- 关键词高亮：控制终端关键词高亮是否启用。关闭后不再对终端输入或输出应用高亮样式，但不会修改真实终端输出内容。
- Keyword Highlighting Configuration：打开关键词高亮 JSON 配置编辑器。配置里可定义规则名称、作用范围、匹配方式、匹配内容和样式。

关键词高亮配置保存后会写入本地配置文件，并用于后续终端输入/输出渲染。

插件安装和内置插件操作位于主界面的插件工作区，不在本设置页。aiopsterm 只接受 `.aiopsterm-plugin` 包，不加载 旧版插件格式。
