# Skills 设置

本页位于 `设置 -> 主机Agent -> Skills`，管理本地技能包。启用后的技能可作为 AI 对话上下文使用。

## 顶部操作

- 打开文件夹：打开用户 Skills 目录。
- Reload：从本地目录重新加载 Skills。
- Import：导入 Skill zip 包。
- Create：新建 Skill。

## Skill 列表

- 启用开关：控制该 Skill 是否可用。
- 编辑：编辑可编辑 Skill 的名称、描述和内容。
- 导出：导出该 Skill 为 zip 包。
- 删除：删除该 Skill。

## Skill 编辑弹窗

- Skill Name：Skill 名称。编辑已有 Skill 时名称不可改。
- Description：Skill 描述，用于告诉 AI 和用户这个 Skill 的用途。
- Content：Skill 主体内容，通常是对模型的任务说明、流程约束或领域知识。
- 创建/保存：写入本地 Skill 文件。

Skill 应该保持聚焦，避免把无关规则堆进同一个 Skill。
