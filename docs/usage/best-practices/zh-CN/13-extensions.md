# 插件与扩展

插件把额外页面、工具或集成入口加入 aiopsterm。安装前应确认来源和权限，出现问题时可以独立停用，不影响核心终端。

## 从哪里打开

点击左侧模块栏的 **扩展** 图标进入插件列表。点击列表中的插件卡片后，中间主面板才会打开详情；点击详情页的 **安装/更新/卸载** 执行生命周期操作。安装本地包时，把受支持的插件包拖到左侧列表底部的虚线投放区，等待校验和确认弹窗。

![插件列表](../images/zh-CN/extensions-workspace.png)

## 浏览与管理

- 搜索框按名称和描述过滤；分类和状态帮助区分内置、已安装和可用插件。
- 详情页展示版本、作者、说明、功能列表、安装信息和插件提供的入口。
- 安装或更新期间显示进度，可取消仍在下载或校验的任务。
- 停用保留配置但隐藏功能；卸载移除插件包，用户数据是否保留以确认页说明为准。

## 信任与权限

外部插件只有在通过清单校验并获得用户信任后才启用。不要安装来源不明的包；插件提供的页面或工具仍需经过 aiopsterm 的 preload、IPC 和后端能力边界，不能把渲染层当作凭据存储。

## Alias 与功能入口

支持 Alias 的插件可在详情页对应标签中创建、编辑、启用和排序别名。先点击插件卡片，再切换到 **Alias** 标签；不要在列表页寻找隐藏的编辑入口。插件声明的页面会出现在详情或相应模块入口，具体位置以功能列表为准。

## 最佳实践与排错

- 更新前记录当前版本；生产环境先在测试机器验证。
- 插件报错时先停用并重启，确认核心功能正常，再检查清单版本和日志。
- 拖放无反应时确认包格式、清单路径和应用窗口焦点。
- 版本不兼容、签名/校验失败或运行时入口缺失时不要绕过校验强行启用。
