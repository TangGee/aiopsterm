# 快捷命令与宏录制

aiopsterm 提供从单条命令到多主机操作的多种入口。快捷命令把常用脚本片段保存在主进程后端；宏录制把真实终端操作变成可回放脚本；AI 命令和 Agent 则适合临时生成或分步排查。

## 从哪里打开

点击模块栏的 **快捷命令**。点击列表工具栏左侧控件选择分组，点击右侧 **新建** 打开编辑面板。执行前先打开目标终端，再点击命令行的运行按钮；从 AI 使用时，在输入框输入 `/` 并点击弹出的命令。宏录制从工具栏录制按钮开始，再回终端完成操作。

## 先选正确的命令入口

| 需求 | 推荐入口 | 执行方式 |
| --- | --- | --- |
| 已经知道命令，只想快速输入 | 终端右键 -> 输入命令 | 浮动输入框，成功写入后关闭 |
| 想让 AI 生成一条命令 | 终端右键 -> AI 命令，或 Classic Command | 先显示可编辑命令卡，再人工执行 |
| 需要多步诊断 | Classic Agent 或主机 Agent | 逐步调用工具，按安全策略审批 |
| 重复运行固定操作 | 快捷命令 | Run 全部提交，Paste 留最后一步确认 |
| 在多个终端运行同一诊断 | 全局执行 | 只向你选择的终端广播 |
| 给自动化脚本调用桌面能力 | `aio` 控制命令 | 通过本地控制 socket 执行和通知 |

> 安全建议：全局执行前先核对所有目标终端的主机、用户和当前目录。不要把高危写操作广播到混合环境。

## 编写可靠的快捷命令

- 创建/编辑必须经后端确认才会更新目录；运行时后端按**片段 ID** 重新取最新脚本，绝不会执行过期草稿。
- `Run` 提交全部命令段；`Paste` 把最后一条留在输入行不回车，适合需要临场改参数的命令。
- 在脚本里用 `sleep==毫秒` 为下一段命令加延时，等待前一步生效（如服务重启后再查状态）。
- 任何一段写入失败即中止后续段，不会把后半截命令打进错误的会话。

推荐的组织方式：

- 按场景分组：`巡检`、`发布`、`数据库`、`应急`。
- 名称用"动词 + 对象"：`重启 nginx 并验证`、`采集 JVM 线程栈`。
- 高危命令不要做成一键 Run 的快捷命令，改用 Paste 模式留人工确认一步。

## 宏录制

1. 在快捷命令面板点击录制，录制器自动选中活跃终端窗格（不会绑到知识库或聊天面板上）。
2. 直接在终端里操作；只有后端确认过会话与字节数的真实输入才进宏，被拒绝或畸形的写入不会录进去。
3. 回车提交当前行；开启控制键捕获后可录制受支持的控制键。
4. 停止录制即保存为带时间戳的后端快捷命令；取消则丢弃。

> 提示：录制期间的输入直接进入宏状态机，不会污染终端回显——你看到的仍然只有 PTY 的原生回显。

## 在 AI 对话中引用

在 AI 输入框键入 `/` 可以把快捷命令作为提及（mention）插入对话，让 AI 基于你的既有脚本改写或解释。

## 多终端和自动化场景

- 终端右键的 **全局执行** 适合对多台同类主机运行同一条只读检查。先拆分或打开目标终端，明确选择范围，再发送命令。
- Classic Command 只生成一条提案；需要读取状态后继续决定下一步时切换到 Agent，不要把多步逻辑压进一条难以审查的 shell。
- 外部脚本可使用 `aio` CLI 查询界面状态、向终端写入命令以及发送通知。先在终端执行 `aio --help` 查看当前安装版支持的子命令；自动化前先用只读查询取得目标终端 ID，写入时显式指定目标，不要依赖当前焦点。
