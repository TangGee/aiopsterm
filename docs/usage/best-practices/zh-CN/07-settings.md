# 设置调优要点

设置项很多，本文只挑对日常体验影响最大的几页，按推荐顺序过一遍。快捷键 `Ctrl+,` 直达设置。

## 通用：主题与背景

![通用设置](../images/settings-general.png)

**① 通用** 页设置主题（Dark/Light）与应用背景（**②** 预设或自定义图片，支持 JPG/PNG/WebP/GIF）。背景开启后，各模块的面板、标签栏、菜单会切换为半透明表面，终端文字区域仍保持可读；选择新预设会自动应用可见度合理的默认透明度/亮度。

## 终端：字体、光标与终端类型

![终端设置](../images/settings-terminal.png)

- **① 终端类型**：写入 xterm `termName` 并作为新会话的 `TERM`（本地 pty、SSH、relay-shell 都生效）；无效值回退 `xterm-256color`。远端程序显示异常时优先检查这里。
- **② 字体**：字体族、字号、行高即时应用到所有已打开的终端窗格与内嵌 Codex 面板；某窗格手动 `Ctrl+=` 缩放过的字号在该窗格关闭前优先生效。
- **③ 光标**：样式与闪烁。
- 其余常用项：Scrollback 回滚行数、Pinch Zoom（Ctrl/Meta+滚轮字体缩放开关）、标签关闭按钮显示、粘贴保护。

## 模型：接入你的推理端点

![模型设置](../images/settings-models.png)

**① 模型** 页管理内置模型与自定义模型。自定义支持 OpenAI Compatible / OpenAI Responses 等提供方：Base URL 已含 `/v1`、`/v3` 版本段时保留原样；结尾加 `#` 阻止自动追加 `/v1`（保存前标记会被剥离）。配置后用 `Check` 验证连通性再 `Save`。

## 快捷键：按习惯重映射

![快捷键设置](../images/settings-shortcuts.png)

**① 快捷键** 页可重映射新建终端、切换指定标签、显示/隐藏 AI 侧栏等应用动作。注意：配置成普通 `Ctrl+字母` 的应用快捷键在终端聚焦时**不会**被捕获——Shell 的 readline 控制键优先。`重置全部` 一键还原。

## 主机Agent：AI 安全策略中枢

![主机Agent 设置](../images/settings-hostagent.png)

`对话与主机` 子页 **②** 集中管理 AI 执行策略：

- `自动执行只读命令`：允许模型声明为非破坏性的诊断命令自动执行；主进程安全策略仍可强制要求审批。
- `安全配置`：命令拦截/确认策略，被策略拦截的命令对 AI 同样拦截。
- `AI 会话自动命名`（默认关）：用配置的模型给完成的回合生成摘要标题，手动改名不受影响。
- MCP / Skills / 规则子页详见 [MCP 集成](06-mcp.md)与 [AI 助手](03-ai-assistant.md)。

## 规则：给 AI 立规矩

![规则设置](../images/settings-rules.png)

**①** `规则` 子页维护 User Rules，启用的条目注入每个 Classic 对话。适合放：公司术语、回复语言、"生产环境命令一律先给 dry-run 版本"这类工作流约定。规则影响风格与流程，但不会绕过安全策略。

## 关于：版本与诊断

![关于页](../images/settings-about.png)

**① 关于** 页除了版本与更新检查，还有两个排障入口：`Open Log Dir` 直接打开运行日志目录，`Feedback` 生成本地诊断报告——报障时先来这里。
