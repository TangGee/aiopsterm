# 快速上手

本文帮助你在 10 分钟内完成 aiopsterm 的首次连接，并认识主界面的四大区域。

## 安装与启动

aiopsterm 桌面安装包自带 Electron 运行时、原生终端模块和内置 Codex 运行时，**无需预装 Node.js 或 npm**。安装后直接启动即可。

由 aiopsterm 创建的本地终端会自动在 PATH 中提供 `aio`、`aictl`、`aiopsterm-control` 和 `aiossh` 命令。日常推荐用短命令 `aio`；已保存主机可直接 `aiossh <主机名>` 连接。

## 认识主界面

![主界面](../images/main-window.png)

| 编号 | 区域 | 说明 |
| --- | --- | --- |
| ① | 模块导航栏（SideRail） | 最左侧图标栏，切换工作区、资产、文件、快捷命令、知识库、数据库等模块 |
| ② | 资源面板 | 当前模块的功能面板；工作区模块下显示主机资源树 |
| ③ | 主工作区 | 终端、文件、数据库、知识文档等主要工作发生的位置 |
| ④ | AI 侧栏 | 右侧 AI 助手区域，支持 Codex CLI 与 Classic 对话 |
| ⑤ | Agents 入口 | 进入 Agents 模式，集中管理全部 AI 产品会话 |
| ⑥ | 设置按钮 | 打开设置工作区（快捷键 `Ctrl+,`） |

欢迎页上直接列出常用快捷键：资产列表 `Ctrl+B`、打开设置 `Ctrl+,`、内联命令生成 `Ctrl+Shift+K`、切换 Terminal/Agents 布局 `Ctrl+E`。

## 第一次连接主机

![连接主机](../images/connect-host.png)

1. 在资源面板顶部切换 **① 直接连接 / 堡垒机资源** 两棵资源树。
2. 主机较多时用 **② 搜索框** 按名称过滤。
3. **③ 双击任意主机行**（如 `prod-bastion`）即可建立 SSH 会话；主机行的 `⋯` 菜单提供编辑、克隆等操作。
4. **④ 本地连接** 下的 `127.0.0.1` 双击后打开本地 Shell，适合先在本机熟悉操作。

> 最佳实践：把常用跳板机、生产入口保存为资产并分组（生产/预发/维护），"最近连接"会自动记录最近 10 个成功连接，高频主机无需翻树查找。

连接时的注意事项：

- 密码认证的主机若未保存密码，会弹出全局认证对话框；勾选 `记住密码并更新该主机` 后，密码只在 SSH 连接真正就绪后才会保存。
- 需要动态口令/OTP 的堡垒机会弹出同一个全局验证对话框，点击空白处不会误关。
- SSH 会话默认开启 keepalive，减少 NAT、防火墙或堡垒机空闲清理导致的断连。

## 集中管理资产

![资产工作区](../images/assets-workspace.png)

模块导航栏中的 **资产** 模块是完整的资产管理工作区，顶部四个页签分别是 **① 主机管理、② 堡垒机管理、③ 密钥管理、④ 代理管理**。在 **⑤ 主机行** 上双击可直接发起 SSH 连接并自动切回终端工作区。

资产管理建议：

- 用右键菜单创建目录和主机：空白处右键建顶级目录，组上右键建子目录或主机，新主机自动继承所在组。
- 私钥统一放入密钥管理（KeyChain），主机表单不再接受直接粘贴私钥文本；一个密钥可被多台主机引用。
- 主机表单支持配置 SSH 代理（HTTP/SOCKS/原始 TCP）与跳板机；表单内可就地新建密钥、代理、跳板机，创建成功后自动回填选中。
- 用 `连接测试` 验证配置：密码被禁用、密码错误、密钥被拒、缺少认证方式、网络不通会返回不同的错误说明，便于对症排查。
