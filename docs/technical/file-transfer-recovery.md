# 文件传输恢复

使用入口、暂停/继续/移除操作见[文件管理指南](../usage/best-practices/zh-CN/10-files.md)。本文描述后端约束与验证方法。

## 任务生命周期与存储

应用启动时，通过 `configureFilesBackendRuntime.transferStatePath` 启用持久化传输引擎。上传文件、上传目录、下载和两台远程主机互传共用该引擎；编辑器保存、文件删除、权限修改等操作不属于可续传任务。

后端在用户数据目录的 `file-transfer-jobs.json` 存储版本为 1 的任务记录：任务状态、源/目标路径、主机资产标识及 host/port/username、覆盖策略、目录清单、文件大小/修改时间/普通权限位、SHA-256、完成标记和临时路径。密码、私钥和口令不写入任务记录；继续任务时从现有资产配置重新解析连接信息。主机地址、端口或用户名改变时拒绝恢复，避免续传到另一台机器。

记录先写同目录临时文件再重命名。读取失败时保留原文件并拒绝新传输，不静默清空记录。应用异常退出后，原 `running` 任务加载为 `paused`，用户点击继续才会运行。成功、失败、暂停和取消记录均保留到用户移除；上限为 100 个任务、32 MiB 记录，目录计划上限为 10000 个条目、128 层。

## 数据传输与恢复规则

- 文件先分块计算源 SHA-256，再以 256 KiB 缓冲区写入目标旁的专属 `.aiopsterm-<task-id>-<entry-index>.part` 文件。目录里的大文件也使用分块读写，不整文件驻留内存。
- 暂停或断线保留已写入部分。恢复前重新检查源大小、修改时间及完整 SHA-256，并对已传前缀做双方校验；校验通过才从临时文件长度继续写入。
- 完成后校验临时文件完整摘要，检查原目标大小/修改时间/类型未变，再重命名为正式目标。覆盖已有文件时保留其普通权限位，新文件采用源普通权限位；不复制所有者、ACL、扩展属性或特殊权限位。
- SFTP 优先使用 OpenSSH 原子重命名扩展；明确不支持扩展时回退普通 SFTP 重命名。如果服务端不允许覆盖，任务报错且保留原文件，不用删除原文件再重命名的方式模拟替换。
- 目标冲突检查使用类型、大小、修改时间；不能检测外部程序刻意保留大小和修改时间的内容修改，也不能排除检查与重命名之间的外部写入。传输目标不宜同时由其他程序修改。
- 目录先生成清单。恢复时重新校验已完成文件，但不重新写入；空目录会创建，符号链接按链接复制，不递归跟随。源目录条目或修改时间变化可能使恢复失败，此时应移除旧任务后重新创建。
- 进度区分扫描、校验、传输。全量摘要和恢复校验增加磁盘或网络读取，因此“校验中”没有传输速度并不表示卡死。

暂停和取消在块间或 I/O 返回后生效，不强制抢断正在写入的请求。暂停可继续；取消不可继续。取消保留临时文件，点击移除时清理该任务未完成文件的临时数据，已完成文件和已创建目录保留。远程清理失败时保留任务供重试，不冒充已清理。

## 并发与界面边界

同一目标主机账号上的相同、祖先或后代路径不可并发写入；不同目标仍可并行。任务运行和清理分别持有独占状态，防止重复继续或一边删除一边写入。

`files:transfer-task:control` 提供 pause/resume/cancel/remove。主进程通过原有事件通道广播状态，进度合并发送。界面挂载任务面板时查询历史并订阅事件；列表以任务 ID 保持行稳定。晚到的列表快照不能覆盖请求期间的新完成事件或恢复已删除任务。恢复成功会刷新当前文件目录，不跳回根目录。

## 回归验证

- `tests/files-resumable-transfer.test.ts`：真实临时文件上的分块写入、暂停/重启恢复、失败重试、源/临时/目标变更、目录跳过已完成文件、空文件与符号链接、目标并发、清理并发与失败、原目标权限、损坏记录。
- `tests/files-transfer-endpoint.test.ts`：SFTP 回调适配、偏移写入、独占临时文件、扩展不支持回退与权限错误不回退；该适配测试使用文件系统模拟服务端，不等同于实机网络测试。
- `tests/files-backend.test.ts`：实际后端入口启用持久化引擎和重载历史，保留既有文件操作回归。
- `tests/files-runtime.test.ts`、`tests/transfer-progress.test.ts`、`tests/workspace-store.test.ts`：持久历史、暂停/继续/重试/移除按钮、行稳定、订阅清理和快照竞态。
- `tests/app-shell.test.ts` 的文件场景：拖拽区域、目录保持、HOME 起始路径、任务面板和文件操作。

运行上述相关用例及 `npm run typecheck`；本次功能不依赖新增 npm 包。实机验收应覆盖不同 SFTP 服务端、真实断网恢复及大目录，不以模拟端点测试替代这些环境验证。
