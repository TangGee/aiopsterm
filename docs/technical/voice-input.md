# 语音输入与输入目标保护

先在语音设置中配置识别引擎和模型，再聚焦需要输入的位置，点击浮动麦克风或使用已配置快捷键。录音结束后检查识别文字，再自行发送；语音输入本身不提交 AI 请求或执行终端命令。

本地 Zipformer 使用麦克风 PCM 实时识别，部分结果更新当前口述范围，结束后填入最终结果和标点。普通输入框、可编辑文本及注册适配器的编辑器分别管理输入位置。密码框和编辑器内部隐藏输入节点不会被当作普通文本目标。

输入位置被移除、隐藏、改为只读，或内容被用户修改时，后续结果保留到语音面板，避免覆盖新内容。Classic 编辑框因空文本状态变化而更新 class 或样式时，口述应继续；样式变化不属于内容修改。可编辑目标仍检查文本节点、子节点、`contenteditable` 属性和实际可见性。

没有可用麦克风时先检查系统输入设备和权限。录音无文字时检查选中的系统默认输入源、音量和静音状态；不要将输出设备的静音 monitor 误作麦克风。录制演示若使用虚拟输入，结束后恢复原默认输入源。

验证入口：`tests/global-voice-targets.test.ts` 覆盖实时替换、样式更新、手动编辑保护与目标失效；`global-voice-recording`、`global-voice-streaming`、`voice-realtime-recording` 测试覆盖音频收尾、取消、识别失败和迟到结果。真实麦克风到识别文字的验收需另外执行，单元测试不能代替音频设备验证。
